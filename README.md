# 100 Days at Sea codes guide

Fan notes for [100 Days at Sea](https://www.100daysatsea.com/) — active codes, redeem steps, and a first-hour build order.

## Codes

Active and working codes are listed on the [100 Days at Sea codes](https://www.100daysatsea.com/codes) page. Check there first when a new batch drops, then redeem in-game before they expire.

## Beginner tips

- Start with the [beginner guide](https://www.100daysatsea.com/beginner-guide) for the first-hour build order.
- Redeem codes early so rewards land before you spend scarce early resources.
- Keep a short checklist of what you still need (food, hull, crew) so each voyage has a clear goal.
